# Enfin lu

Les grands classiques en épisodes de deux minutes. Site de l'appli, servi par GitHub Pages.

## Référencement (lot V3a)
À chaque nouvelle version du site, après le script de fabrication : `python3 outils/seo.py index.html`
(titre, description, balises de partage, données structurées, texte de présentation ; sans effet s'il a déjà été passé).
robots.txt, sitemap.xml, 404.html et partage-1200x630.jpg ne sont pas touchés par les scripts de fabrication.
